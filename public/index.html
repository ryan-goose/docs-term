About docs-term

A localhost Google Docs–lookalike that is a real Linux terminal (PTY via node-pty + xterm.js).

Shell prompts often set cell backgrounds (ANSI SGR 40–47 / 48 / 100–107). On a white Docs page those paint as a black strip. Use Highlight → No cell backgrounds to rewrite those codes to default (49) before display, keeping foreground colors.

Bound to localhost only. Do not expose the port.
